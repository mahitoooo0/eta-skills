# Android 写操作纪律（root）

适用：改系统分区、刷模块、改 SELinux 上下文、替换系统二进制、`/data` `/system` `/vendor` 下的任何写操作。本技能正文默认只读；执行本文件的流程前，确认用户已明确授权本次写操作的目标与范围。

## 五步闭环

1. **改前快照**（一行不省）：
   ```bash
   ls -lZ <目标路径>            # 权限 + SELinux 上下文
   sha256sum <目标文件>
   mount | grep <所在分区>       # 确认分区与读写状态
   ```
   快照写进本次任务的 notes.md。
2. **回退预案先写后改**：回退命令整理成一行序列（还原备份 → 恢复上下文 `restorecon` 或 `chown/chcon` → 重启相关服务），先贴进 notes.md 再动手。写不出回退命令的操作不动手。
3. **原子替换**：新文件先写到**同分区**临时路径（跨分区 mv 是拷贝，不原子）→ 校验 sha256 与可执行位（系统二进制 0755）→ `mv` 原子替换。
4. **立即验证**：功能验证（`--version`、试跑、重启服务后行为复查）+ 权限上下文复查（`ls -lZ` 与快照对比）。
5. **失败留痕**：任何非零退出、`dmesg | grep avc` 与 logcat 的 denied 记录、操作序列与时间，写进 notes.md。诊断信息不落盘等于白修。

## 模块安装（KernelSU/Magisk 类）

- 优先用管理器自带命令（如 `ksud module install <zip>`），不手工解压进 modules 目录。
- 安装后确认三件事：模块目录出现、`module.prop` 可读、disable/uninstall 标志未置位。
- 记录模块 id 与版本；回退走管理器卸载，不手工删目录。

## 红线

- `/data/adb/` 下不属于本次任务目标的任何内容：不碰。
- 无法回退的操作（覆盖无备份的分区镜像等）：除非用户明确说明已接受风险，先问。
- 一次只做一个系统级变更；多个变更排队，每个独立验证通过再做下一个。
