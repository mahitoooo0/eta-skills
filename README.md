# eta-skills

Eta（Android 系统级 AI 助手）的技能仓库。每个顶层目录是一个技能（含 `SKILL.md`）。

- `android-*` / `coding-repo-workflow` / `linux-workspace-ops` / `subagent-orchestration` / `web-research`：为本机 Eta 运行时定制（root shell、GUI 自动化、GitHub 工作流、子代理编排、浏览器调研、chroot 环境与网络修复）。
- 其余目录：方法论技能，源自 obra/superpowers（commit 8ca22dba），已按 Eta 运行时（中文、无 shell 的子代理、`terminal(environment=linux)`、`supervise_task`/`continue_task`）改写。其中 `doubt-driven-development` 与 `constraint-driven-development` 的悬空引用已清理（2026-10-04）。

## 安装（手机 Eta 内）

对 Eta 说：「从 mahitoooo0/eta-skills 安装技能」，或在技能页用 skill-installer 检查该仓库后多选安装。
