# 技能设计中的说服原则（Persuasion Principles for Skill Design）

## 概述

LLM 会对人类同样起作用的那些说服原则做出反应。理解这套心理学能帮你设计更有效的技能 —— 不是为了操纵，而是为了让关键做法在压力下也被执行。

**研究基础：** Meincke 等（2025）用 N=28,000 段 AI 对话测试了 7 条说服原则。说服技巧让遵守率翻倍以上（33% → 72%，p < .001）。

## 七条原则

### 1. 权威（Authority）
**是什么：** 对专业、资质或官方来源的服从。

**在技能里怎么用：**
- 命令式语言：“你必须”、“绝不”、“始终”
- 不可协商的措辞：“没有例外”
- 消除决策疲劳和狡辩空间

**什么时候用：**
- 执行纪律的技能（TDD、验证要求）
- 涉及安全的做法
- 已成共识的最佳实践

**例子：**
```markdown
✅ 写测试前先写了代码？删掉。重来。没有例外。
❌ 可行时可以考虑先写测试。
```

### 2. 承诺（Commitment）
**是什么：** 与先前行动、声明或公开表态保持一致。

**在技能里怎么用：**
- 要求声明：“声明你正在使用哪个技能”
- 逼出明确选择：“选 A、B 或 C”
- 用可追踪的清单：在回复里维护编号待办清单（Eta 没有 todo 工具，就用编号列表）

**什么时候用：**
- 确保技能真的被遵循
- 多步流程
- 问责机制

**例子：**
```markdown
✅ 找到技能后，你必须声明：“我正在使用 [技能名]”
❌ 可以考虑告诉用户你在用哪个技能。
```

### 3. 稀缺（Scarcity）
**是什么：** 由时限或有限可用性带来的紧迫感。

**在技能里怎么用：**
- 带时限的要求：“在继续之前”
- 顺序依赖：“紧接着 X 之后”
- 防拖延

**什么时候用：**
- 即时验证要求
- 时间敏感的工作流
- 防“我待会儿再做”

**例子：**
```markdown
✅ 完成一个任务后，立即请求代码评审再继续。
❌ 方便的时候可以评审代码。
```

### 4. 社会认同（Social Proof）
**是什么：** 向他人做法或“正常做法”靠拢。

**在技能里怎么用：**
- 普适模式：“每次”、“始终”
- 失败模式：“X 而不做 Y = 失败”
- 建立规范

**什么时候用：**
- 记录普适做法
- 警告常见失败
- 强化标准

**例子：**
```markdown
✅ 清单不逐项跟踪 = 步骤会被跳过。每次都是。
❌ 有些人觉得用待办清单跟踪检查项有帮助。
```

### 5. 共同体（Unity）
**是什么：** 共享身份、“我们感”、同一阵营的归属。

**在技能里怎么用：**
- 协作性语言：“我们的代码库”、“我们是同事”
- 共同目标：“我们都想要质量”

**什么时候用：**
- 协作型工作流
- 建立团队文化
- 非层级化的做法

**例子：**
```markdown
✅ 我们是同事，在一起做事。我需要你诚实的专业判断。
❌ 你觉得我错了的话，最好告诉我一下。
```

### 6. 互惠（Reciprocity）
**是什么：** 回报所受好处的义务感。

**在技能里怎么用：**
- 少用 —— 容易显得在操纵
- 技能里几乎用不到

**什么时候避免：**
- 几乎总是（其他原则更有效）

### 7. 好感（Liking）
**是什么：** 更愿意与喜欢的人合作。

**在技能里怎么用：**
- **不要用于合规**
- 与诚实反馈文化冲突
- 会造出谄媚

**什么时候避免：**
- 执行纪律时永远避免

## 按技能类型组合原则

| 技能类型 | 用 | 避免 |
|------------|-----|-------|
| 执行纪律型 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技术型 | 适度权威 + 共同体 | 重权威 |
| 协作型 | 共同体 + 承诺 | 权威、好感 |
| 参考型 | 只要清楚 | 所有说服技巧 |

## 为什么有效：心理学机制

**明线规则减少狡辩：**
- “你必须”消除决策疲劳
- 绝对化语言消除“这算例外吗？”的追问
- 明确的反狡辩挡板堵住具体漏洞

**执行意图让行为自动化：**
- 明确触发 + 必需动作 = 自动执行
- “当 X 时，做 Y”比“一般要尽量做 Y”更有效
- 降低遵守所需的认知负担

**LLM 是“类人”的：**
- 训练文本里充满这些模式
- 权威语言在训练数据里先于服从出现
- 承诺序列（声明 → 行动）被大量建模
- 社会认同模式（大家都做 X）建立规范

## 伦理边界

**正当：**
- 确保关键做法被遵循
- 写出有效的文档
- 预防可预见的失败

**不正当：**
- 为私利操纵
- 制造虚假紧迫
- 用内疚逼人服从

**检验标准：** 如果使用者完全理解这套技巧，它是否仍然服务于他的真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 说服的七条原则
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 用 N=28,000 段 LLM 对话测试 7 条原则
- 使用说服技巧后遵守率从 33% 升到 72%
- 权威、承诺、稀缺最有效
- 支持 LLM 行为的“类人”模型

## 快速参考

设计技能时问自己：

1. **它是哪一类？**（执行纪律 vs 指导 vs 参考）
2. **我想改变什么行为？**
3. **该用哪几条原则？**（执行纪律通常是权威 + 承诺）
4. **是不是叠得太多了？**（不要七条全上）
5. **这正当吗？**（服务于使用者的真实利益吗？）
